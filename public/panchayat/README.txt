Photographs of the Gram Panchayat office, shown on the About page.

Currently in use:

  office-front.jpeg   front of the building, entrance and stone steps
  office-back.jpeg    corner of the building and the courtyard wall
  office-rear.jpeg    rear of the building, from the village path

The file names and captions are listed in PANCHAYAT_PHOTOS in
app/config/panchayat.js. If you add, rename or remove a photograph here, edit
that list to match — the name and the extension must agree exactly, including
.jpeg versus .jpg.

Any entry whose file is missing removes itself from the grid, so the page never
shows a broken image.

Please resize to about 1600px on the long edge before saving. A photograph
straight off a phone is several megabytes and is slow on a village mobile
connection.
